About these tests

MouseBench is a collection of browser-based tools for testing your mouse hardware and reflexes. Every measurement happens locally in your browser using standard web APIs — mouse buttons via MouseEvent, the scroll wheel via WheelEvent, and movement for the DPI tool via movementX/movementY. Nothing you do here is uploaded to a server.

Each tool lives on its own page so you always land exactly where you need, and results never wait for a network round-trip.

Heads up: browsers can’t read raw hardware DPI or true end-to-end latency. Our DPI and latency tools use the most accurate approaches available in-browser and clearly explain their limits.

Frequently asked questions

Are these mouse tests free?

Yes — every tool on MouseBench is completely free, runs in your browser and requires no account or download.

Is my mouse data sent anywhere?

No. All events are processed locally by JavaScript in your current tab. You can verify with your browser's network panel — no requests are fired by the tests.

Can I use these testers on a laptop touchpad?

Button tests, scroll tests and click speed work fine with an external mouse or touchpad. DPI, latency and the aim challenge work best with a real mouse, but remain usable with touch.

Which browsers are supported?

All modern browsers: current Chrome, Firefox, Edge, Safari and Brave. Side buttons (buttons 4 and 5) require Chrome 49+, Firefox 52+ or equivalent.

What does the aim & memory challenge measure?

It combines aim accuracy with short-term memory: numbered circles appear, the numbers hide, and you click them back in order. Rounds grow harder as circles shrink and display time shortens.
