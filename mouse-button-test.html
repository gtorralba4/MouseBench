    How to use this mouse tester

    • Click the left, right, middle and side buttons on your physical mouse and confirm the matching zone lights up blue while pressed.
    • Each zone turns green once tested. A red flash while you press means events fired that shouldn’t have.
    • Hover over the diagram and spin the scroll wheel — both arrows should light up. The scroll-distance counter tells you how much a single flick produces.
    • Watch the double-click counter: if it climbs while you’re only single-clicking, the left switch is bouncing — the classic sign of switch wear.

    Switch mouse models

    Pick 3-button, 5-button or MMO 9-button above the diagram. The diagram adapts: gaming mice add thumb buttons. Note that browsers only report two distinct side-button values (4 & 5 / back & forward) — extra thumb buttons on MMO mice share those values, so verify extra macros in your vendor software.

    Tip: testing buttons 20–30 times in quick succession is the best way to expose an intermittent or bouncing switch.

    Frequently asked questions

    What does double-click detection actually test?

    It counts dblclick events. If that counter rises while you’re deliberately single-clicking slowly, the left micro-switch is bouncing from wear — the first stage of double-click failure.

    Why don’t my extra thumb buttons light up?

    Browsers only expose two side-button events (values 3 and 4, usually mapped to back/forward). Buttons beyond that can’t be individually detected by any website — use Logitech G Hub, Razer Synapse or similar to test them.

    The right-click menu keeps appearing — can I still test it?

    The context menu is suppressed inside the diagram area so right-click works normally there. Outside that area standard browser menus still apply.

    Does this send my mouse data anywhere?

    No. Everything runs locally with JavaScript; no network request is made.
